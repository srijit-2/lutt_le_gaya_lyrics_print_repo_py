# 🎵 Python Terminal Lyrics Player

A simple and fun Python project that displays song lyrics in the terminal with a **typing animation effect**, colorful text, and timed delays for a music-like experience.

## ✨ Features

* 🎶 Displays lyrics line by line
* ⌨️ Character-by-character typing animation
* 🌈 Alternating text colors in terminal
* ⏳ Custom delays between lyrics lines
* ❤️ Stylish terminal output with song title

## 🛠️ Technologies Used

* **Python**
* `time` module
* `sys` module

```bash

```

3. Run the Python file:

